# Triage labels

Use these exact label names in GitHub and Linear. A triaged issue gets one state label. Linear's workflow status tracks implementation progress separately.

| Label | Meaning |
| --- | --- |
| `needs-triage` | Awaits maintainer review |
| `needs-info` | Awaits information from the reporter |
| `ready-for-agent` | Fully specified and ready for an agent |
| `ready-for-human` | Requires human implementation |
| `wontfix` | Closed without implementation |

For category labels, use `bug` and `enhancement` in GitHub and `Bug`, `Feature`, or `Improvement` as appropriate in Linear.
